# F-Droid publishing handoff

This repository now contains Fastlane store text and an F-Droid metadata template. Before submitting, choose and add the project's open-source licence, publish the source repository, replace every `TODO` in `com.example.quietnote.yml.template`, set a non-placeholder Android application ID, and produce a reproducible release build.

The current identifier, `com.example.quietnote`, is intentionally treated as a development placeholder and should not be published unchanged.
